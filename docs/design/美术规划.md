# 区域美术规划

**owner 决定（2026-10-22）：全部地图用固定斜视的体素表现，按饮风客栈二楼的丰富程度布置。**
长期规则在 `AGENTS.md`「Maps and art」，本文件是各区域的美术依据和体素规范。

目的：玩家看地形、植被、建筑和颜色，就知道自己在哪个地区。所有地区用同一套体素美术体系，差别来自
地貌与空间、地表和建筑材料、植被、主色和点缀色、地标与生活道具。第一版每个地区用一套稳定外观，不做
动态四季。

依据只认原版 LPC：`reference/es2/mudlib/`（只读，下文路径省略这一段前缀，写作 `d/snow/square.c`）。
- 原文写明的保留。
- 原文没写的颜色、材质、季节感标「美术提案」。
- 和原文冲突的设计不做。
- 不凭地名推气候：雪亭镇不铺雪。

> 全局规则（影响所有室外图）：原版有一套 8 段的昼夜循环，加在每个 `set("outdoors")` 的房间上：
> 微曦、日出、上午、正午、下午、傍晚「火红的夕阳」、夜晚、午夜「满天繁星」。
> 来源：`adm/daemons/natured.c`、`adm/etc/nature/day_phase`、`cmds/std/look.c:61`。
> 原版没有任何雪、季节、结冰机制。所以室外美术要画成可以染色的中性日光，夜色由运行时叠加（见问题 1）；
> 室内不随昼夜变，靠灯火。

## 2. 体素规范

- **视角**：固定正交斜视，镜头只平移、不旋转。室内近侧（南、东）墙剖成矮墙（体素配置的 `low_walls`），
  远侧墙完整立起；屋顶、树冠只在人物附近局部渐变透明，不整栋隐藏。
- **尺度**：1 体素单位 = 32 世界像素（地图格 16 像素 = 半单位）。人物约 1.85 单位高；室内墙 3.2 单位；
  门扇 2.2 单位，门框常在。
- **体块与色**：全部由方块构成，不描边。每种材质 3～5 档色阶，暗部偏该地区的冷色，亮部偏暖。
- **光**：白天日光加窗光；每张图都要有夜间光源（灯笼、吊灯、窗光、月光），昼夜只改画面。
- **同源**：挡路的家具只写在地图布局的阻挡格上（`look`：种类、朝向、颜色），画面按这个框画；
  不挡路的装饰（灯、窗、地毯、挂画、布鞋）写在 `game/data/<区域>/voxel/<地图>.json`。
- **丰富度标准**（每个房间、街道、野外都要做到，不论地区风格）：
  1. 原文写到的东西都要有（招牌、红木门、木架、旗杆、石狮……），新增的不能和原文矛盾。
  2. 按房间用途配齐家具（客房：床、叠被柜、洗漱架、衣架、行李箱；店铺：柜台、货架、货物），
     再加生活细节（布鞋、茶具、书、坛罐）。
  3. 同类房间各不相同（主题、家具、配色）；每个地区守住自己的主色和材质（第 1 节）。
  4. 室外铺满地表细节和植被；室内地面边缘要满，留出的行走区可以简单。
  5. 门、出口、刷怪点和 NPC 交互范围保持通畅；新增家具在布局里加阻挡，走查测试必须通过。
- **owner 定的四条（2026-10-21）**：
  1. 同一张图里有重复的房间（客房、成排的店），每间的装饰风格要不同：家具、墙色、地面、摆设各不一样。
  2. 所有出入口都有一个上下晃动的三角箭头（运行时统一做：通道指向出口方向，门指向玩家所在一侧的对面）。
  3. NPC 暂时不必精细设计，以后统一做。
  4. 房间外围的背景要合理：门外要有路面向外延伸，不能是一片空地。

## 4. 每张地图的做法

1. 读原文房间描述，列出必须出现的东西和适合用途的家具。
2. 挡路的家具：在 `tools/maps/layouts/<区域>.json` 加阻挡格和 `look`，重画地图（`python -m tools.maps.paint`）。
3. 其余装饰、灯光、剖面墙：写进该图的体素配置，场景布局里 `scene.presentation` 指向它。
