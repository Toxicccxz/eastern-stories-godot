# 区域美术规划

**owner 决定（2026-10-22）：全部地图用固定斜视的体素表现，按饮风客栈二楼的丰富程度布置。**
长期规则在 `AGENTS.md`「Maps and art」，本文件是各区域的美术依据和体素规范。

目的：玩家看地形、植被、建筑和颜色，就知道自己在哪个地区。所有地区用同一套体素美术体系，差别来自
地貌与空间、地表和建筑材料、植被、主色和点缀色、地标与生活道具。第一版每个地区用一套稳定外观，不做
动态四季。

依据只认原版 LPC：`reference/es2/mudlib/`（只读，下文路径省略这一段前缀，写作 `d/snow/square.c`）。
- 原文写明的保留。
- 原文没写的颜色、材质、季节感标「美术提案」。
- 和原文冲突的设计不做。
- 不凭地名推气候：雪亭镇不铺雪。

> 全局规则（影响所有室外图）：原版有一套 8 段的昼夜循环，加在每个 `set("outdoors")` 的房间上：
> 微曦、日出、上午、正午、下午、傍晚「火红的夕阳」、夜晚、午夜「满天繁星」。
> 来源：`adm/daemons/natured.c`、`adm/etc/nature/day_phase`、`cmds/std/look.c:61`。
> 原版没有任何雪、季节、结冰机制。所以室外美术要画成可以染色的中性日光，夜色由运行时叠加（见问题 1）；
> 室内不随昼夜变，靠灯火。

## 2. 体素规范

- **视角**：固定正交斜视，镜头跟人平移；左右两个 45° 视角（昼夜按钮旁切换，0.6 秒平滑旋转，DECISIONS
  「固定俯视体素地图」）。室内近侧墙随视角剖成矮墙（体素配置的 `cutaway_rooms`：每个房间的南墙和朝镜头一侧的墙；
  个别图用 `low_walls` / `low_walls_left` 按右、左视角逐块写），远侧墙完整立起；屋顶、树冠只在人物附近局部渐变透明，不整栋隐藏。
- **尺度**：1 体素单位 = 32 世界像素（地图格 16 像素 = 半单位）。人物约 1.85 单位高；室内墙 3.2 单位；
  门扇 2.2 单位，门框常在。
- **体块与色**：全部由方块构成，不描边。每种材质 3～5 档色阶，暗部偏该地区的冷色，亮部偏暖。
- **光**：白天日光加窗光；每张图都要有夜间光源（灯笼、吊灯、窗光、月光），昼夜只改画面。
- **同源**：挡路的家具只写在地图布局的阻挡格上（`look`：种类、朝向、颜色），画面按这个框画；
  不挡路的装饰（灯、窗、地毯、挂画、布鞋）写在 `game/data/<区域>/voxel/<地图>.json`。
- **丰富度标准**（每个房间、街道、野外都要做到，不论地区风格）：
  1. 原文写到的东西都要有（招牌、红木门、木架、旗杆、石狮……），新增的不能和原文矛盾。
  2. 按房间用途配齐家具（客房：床、叠被柜、洗漱架、衣架、行李箱；店铺：柜台、货架、货物），
     再加生活细节（布鞋、茶具、书、坛罐）。
  3. 同类房间各不相同（主题、家具、配色）；每个地区守住自己的主色和材质（第 1 节）。
  4. 室外铺满地表细节和植被；室内地面边缘要满，留出的行走区可以简单。
  5. 门、出口、刷怪点和 NPC 交互范围保持通畅；新增家具在布局里加阻挡，走查测试必须通过。
  6. 室内要有生活气息（owner，2026-10-26：「太整洁太枯燥」）：每个房间在布局里写用途（`life`：`use`、`wealth`、
     `seed`，原文说干净的加 `tidy`），按 `game/data/common/room_life.json` 的预设统一生成，不逐张手摆。画图工具在
     墙边和角落放会挡路的杂物（麻袋、铁器、坛罐、箱笼……，靠墙斜放的只放北墙），避开门、出口、标记点和柜台前，
     且不改变任何地方能不能走到；体素视图按走动路线磨亮地板、门口带泥，墙根发黄、水渍、补丁，火和灯上方熏黑，
     按用途挂东西、桌上留碗筷酒壶账本，不整洁的屋子椅凳拉歪、角落蛛网和碎屑。墙按用途换材质（粉墙、木板、
     青砖、土墙）。原文写到的优先，和原文矛盾的不放（药铺「闻不到一丝药味」就不挂草药）。
  7. **以后所有地图都按这套风格做**（owner，2026-10-26，合并 #168、#169 时定）：古代、旧、有人住过用过，不要现代式的
     整齐。看颜色就知道在哪个地区（第 1 节的主色、材质、植被，点缀只用本地区的）；铺地成行但长短不一、接缝错开，有
     磨损、裂、断、下陷（`slabs`），原文写「整齐」也是指成行，不是机器切的；不同地面相接处互相咬合、有泥和碎石，
     不是一条直线（`_fray_seams`，只有车辙这类一格宽的保持直线）；室内按第 6 条做出生活气息。暖色、饱和、有层次，
     不做整片发灰。新区域照此做，前后对照图先自己看。
- **路和空间（owner，2026-10-25，先于丰富度；DECISIONS「地图尺寸以体素视角为准」）**：画上体素之后路会被南边
  的东西挡住、被人堵住，所以每个区域在铺装饰之前，先按体素视角重新量路、台阶、院子和厅堂通道，该放宽就在
  `tools/maps/layouts/<区域>.json` 里放宽，不拘泥于原 2D 尺寸：
  1. 至少两人并排；路中间站着一个人，能从旁边绕过去且不碰到他（测试：路线每一段放一个人，寻路时他周围
     5×5 格算阻挡，仍有路）。大路约 192 像素，台阶两侧栏杆之间约 160，小径 144–160，厅堂门洞约 128。
     城镇里两侧有房的街约 300–320（房子在斜视角下要盖住约 120 像素的路面），主街和广场明显比小巷宽；

## 4. 每张地图的做法

1. 读原文房间描述，列出必须出现的东西和适合用途的家具。
2. 挡路的家具：在 `tools/maps/layouts/<区域>.json` 加阻挡格和 `look`，重画地图（`python -m tools.maps.paint`）。
3. 其余装饰、灯光、剖面墙：写进该图的体素配置，场景布局里 `scene.presentation` 指向它。
4. 白天、夜晚各截图自查；跑走查测试，确认门、出口和交互都可达。
