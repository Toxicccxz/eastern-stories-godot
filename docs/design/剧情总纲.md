# 剧情总纲

_ROADMAP「After the grey box」第 3 步（游戏圣经）与第 4 步前半（主线、势力线的设计）并成的一份设计文档。
它定正典、定主线、定每条势力线和新区域的「定位」，不设计任务系统的数据格式和代码（那是下一步）。_

**证据级**（沿用考据稿 `build/story_research/ES2_WORLD_STORY.md`）：【明文】原文直接写了；【传闻】原文里 NPC 或房间
「据说」；【脚本】源码里有、玩家未必见过；【残稿】原作写了一半；【推论】从原文合理推出；【续写】我们新写的。
凡标【续写】的，owner 不同意就划掉；每条续写都说明它和原文怎么接。路径省去 `reference/es2/mudlib/`。

**读法**：§1–§2 是正典（世界是什么样）；§3–§6 是设计（玩家经历什么）；§7–§8 是怎么做；§9 是要 owner 拍板的三题；
§10 是写台词时的规矩。

## 1. 正典三条底线 + 伪墓

**底线一：妖魔是真的，人祸也是真的。**【续写，接 `doc/help/history:40–62`、`myth:3–8`】
侮天鬼是寒於氏斩首、被穿灵镇压五千年的妖魔，三百年前於兰淳焉拔剑放出，至今在找自己的头【明文 history:51–60】。
它的头颅被太阳神族「用强力法术封住」【明文 history:60】——我们把封地定在**玉螺湖底的玄冰之下**【续写，接
`d/village/lakebottom1.c:9` 的「北极的玄冰」和 `lakebottom2.c:11,20` 的六条白鳞冰龙】：渔夫口中「又吃了几个人」的水怪
【明文 `d/village/npc/fisher.c:19`】是封印松动后爬上来的鬼卒，冰龙是守封物的，不是水怪。
与此并行的人祸：失踪的村民（玉螺湖村农妇的七岁儿子【明文 `d/village/npc/woman1.c:18,22`】、黑松阁地牢里的小娟【明文 `d/chuenyu`】）、
天驼关的假印鉴【脚本 `d/canyon`】、二十年前老松岭的灭口，都是兵部尚书庾子建借「寻剑令」干的【续写，接
`d/city/shangshu/npc/shangshu.c:5–12` 的「掌管兵马大权」「当年战功赫赫」与 `npc/walker.c:32` 的「老不死的把持朝廷」】。

没有血统、没有前世。他特殊在**跨地区积累的信任和证据**：第十章谁能拔旋芒、终章谁来帮忙、结局怎么讲，都从事迹记录里长

**伪墓。**【续写，接 `d/oldpine/cave5.c:66` 石壁刻字与 `d/waterfog/npc/elder5.c:7` 活着的南危水】
老松岭瀑布山洞里的骸骨不是南危水。那是二十年前替他挡刀的无名随从，南危水活着爬回水烟阁，却默认了「五长老已死」的说法，
因为伏击他们的人穿的是朝廷武官的白衣。石壁上第一人称的「昔年五长老中第一高手」【明文 cave5.c:66】是活人回来刻的。
这是第一桩玩家可以自己推理的疑案（§3 第一、二章）：骸骨的年纪身量对不上五十二岁的名家、焦殇剑不在洞里、字是刻给活人看的。
研究稿的「替身说」不采；南危水只有一个，活着。

## 10. 文风指南（一页）

* **可译的中文**：短句，一句一个意思；少用典、不靠双关、不靠谐音；人名地名能音译就别带义；量词、时辰、里数保留但首次出现给
  参照（「西南二十四里——走一个时辰」）。
* **原文照抄的不动**：ES2 的房间描述、NPC 台词原样用，含「著」「麽」这类用字；新写的台词用简体规范字，但人物口吻跟原文接上。
* **各人各腔**：店小二碎嘴（「小哥您有所不知」）；柳淳风端着；南危水说一半留一半；程不平文官腔，句句有出处；槐阳王直来直去，
  不说「本王」；商玦不吼，说话像念经；大秦人说中原话带省略、不带错字；浪人少话，一句一顿；少年皇帝像十六岁，不像皇帝。
* **不做文化科普**：门派即公会、内力即法力、辈分即军衔，靠界面和规则呈现，不在台词里解释；玩家角色「已经熟悉这些事物」
  【明文 story:17】。
* **不出现其他玩家**：拒收、拒见、拒卖的话都对着「你」说（DECISIONS「Modern fixes」）；不写「众位玩家」「本服」。
* **选择要看得见**：每个选择的后果至少在一处世界里能看见（一个人在不在、一座村烧没烧、一面碑换没换字），不只在结局讲述里。
* **妖魔不解释**：侮天鬼不讲话、不讲道理；讲道理的是商玦。
* **恶搞不进正典**：出戏的话只在「江湖怪谈」开启时出现。
