* **战斗**：半自动遭遇战（逃跑、投降），ES2 招式描写，武器、护甲、内力、特殊招式和法术；同一区块里见人就打的
  一起出手，出手前有提示一拍（「进门一起上」）；楼里进房间就动手（「室内察觉」）；了结 / 放过（「了结 / 放过」）；
  战斗速度 慢 / 标准 / 快。数值跟着成长走（「战斗数值」）：命中力按 Elo 式指数、守方打五折、经验防御有上限，经典 = combatd.c 原式；
  打之前有五档预判 + 一句原因（目标详情、交互窗口、确认页，整伙合计，切磋按谁先打中）；前两小时的敌人按四档重定（老鼠不再是 110 回合）。
  决策层（「战斗决策」）：每回合等玩家出招（「改为自动」回到 ES2 的自动打），招式表是按钮、点哪招出哪招，每招一个标签 快 / 重 / 虚 / 守 和克制环，
  姿态 攻 / 守 / 游走，NPC 的下一招「起手」和绝招的蓄势一拍看得见（虚招或绝招打中就打断），绝招冷却 2 回合。
  内容（「战斗内容」）：16 个门派的招全有标签；NPC 有原型（稳健 / 爆发 / 守势 / 兽：加权抽招、受伤换档）、绝招用过要歇 3 回合（原型可改）；
  识招——没看熟的招起手写「？」，看两次认得标签和破绽，自家门派一学就认得，百科「武学」有见识录（存档里带）；勇气门那一抽提前到起手，
  过不了门写「起手：守势」（它在等你打空反击）；绝招名带到结算（「封」字诀）；探哨 / 土匪 / 狼狗的气按探针调回它那一档 4–8 回合。
  界面（「战斗界面」）：卡片气条按伤势分四段色、有效上限以下是暗红裂痕，状态是一字标签 + 悬停说明，对手卡只有气条和名字后的强弱一词；
  每一击一条短句（谁 · 招 → 谁 −N · 伤势），原句悬停可见、记录面板里灰字在下；招式悬停有 ES2 原句，方向键在两行按钮间走。
  演出（「战斗演出」）：句子讲到哪演到哪——出手者卡片招名砸字（绝招金色）、被打者飘「−N」/ 闪 / 挡、气条按这一击先掉、闪红加震动，新伤的裂痕一闪、斜纹，
  倒下的卡片下沉盖「倒」/「亡」，定格里盖「胜」/「败」，轮到你时出招行亮起、选中招跳一下，对手的起手 / 要出换了就一闪；时长全在 `feel`。
  拍数（「战斗拍数」，包 A 内核）：一回合是一串拍——双方基础 2 拍（NPC 按 `beats`：小兵 1、头目 2），重招 2 拍，交手序结算，忙按拍没收，
  每回合最多赢 1 拍、赢法由武学骨架定（封山剑法：对手打空「隙」，if 对手重招打空 → 封；柳家拳：近身打实「压」、荒山虎吟近身才能出，if 打实 → 荒山虎吟）；
  NPC 预告是拍计划（第 1 拍确定、预判只被可见事件改并记「变招」）；经典 = 双方 1 拍、ES2 原节奏。
  玩家一侧（「战斗拍数 B」，包 B）：点一拍结算一拍（点一招 → 这一拍 → 对手的下一拍 → 等下一次点，不走时钟）、「收势」放弃余拍、出不起的招变暗写「手不够」、
  排定的绝招 / 运功 / 物品 / 逃和换姿态按拍价扣、「改为自动」补满拍且演出加快；对手卡的拍计划印章（实心朱印 + 空心「？」）与打法词、
  底部短句折后拍「又出两招 −12 −9」。
  面板第二轮（「战斗界面 · 节拍条」）：拍在界面上叫「手」；最上一条节拍条（还剩 N 手、一格一手、重招两格连成一块、能挣的第三手是虚线格写挣法、
  一句话写他起手 / 上一手的结果 / 指着的招占几手与虚影）；出招按标签分快 / 重 / 虚 / 守四栏、副行只写「标签 · N 手」（不再写「克他这招」）；
  绝招一钮一价、运功收成一个菜单、右边克制环；矮屏（960×540、853×480）放得下；经典面板没有节拍条、价钱和收势。
  场景里打与声音（「战斗拍数 C」，包 C）：体素人物随句子出招——定格只给重招 / 绝招 / 致命，出手者滑一步（快短重长）、受击者按克制退半步到一步（克 / 相持 / 被克三种闪色与距离）、
  回合末归位、柳家拳近身站得更近，蓄势前倾 / 受击后仰 10°，闪白一帧 + 脚下一团尘；快 = 短冲 + 残影、重 = 蹲压停半拍再冲 + 定格、虚 = 冲到一半急停、守 = 沉身 + 格挡弧光；

## Known issues

* A failed attack chain ends the fight with 战斗出错，已中止。 (development builds log why); the cause
  still has to be fixed in the content or rule that tripped it.
* Beasts cannot be asked to spar (ES2's `fight` on a beast is a one-sided kill); attack them.
* NPCs never flee a losing fight (`wimpy`) and do not follow who flees (`pursuer`). Nothing can be put into a corpse.
* On the player's own map a wanderer moves only where the player is (ES2's heart beat); other maps are
  caught up when the player comes back.
* Conditions do not tick in a fight (owner) nor while the player lies unconscious.
* A zone that merges several rooms (10 of them) shows only its first room's text.
* 绮云镇: 熟牛肉 is not in the game (nobody sells it in ES2); a carried 布袋 is not opened.

  采药老者's growth lasts only as long as he does (his save file is not ported).

  suites drive combat through a test-only cadence (`historical_world_combat_fixture.gd`). The legacy

* Room labels and NPC names overlap in places on the 2D maps. An NPC that walks away from the player
  stays selected (its actions are refused, kill.c `present()`); one the player walks away from does not.

## How to verify

`SCRIPT ERROR` line, or when `python tools/l10n/extract_pot.py` was not run after a text change). Single
suites: `<godot> --headless --fixed-fps 60 --path game --script res://tests/run_suite.gd -- <suite paths>`. Maps: edit
`tools/maps/layouts/<region>.json`, then `python -m tools.maps.paint <region>` (the tools tests fail on a
hand-edited scene). A longer soak: `ES_SOAK_HOURS=8` before the `world_soak_test` suite.
