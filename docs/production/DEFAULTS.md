_统一试玩之前请过一遍。过完、拍了板，这一页整页删掉：否决的那几条另开包改，认可的不必再记（DECISIONS 里原条目照旧）。_

规则（owner 2026-10-08，DECISIONS「积压问题的处理」）：PR 合并时 owner 没回答的问题按 PR 的推荐生效、在 DECISIONS 里标「默认」，owner 随时可以否决。这些决定大多没有逐条给 owner 看过，而且多半是十月上旬用英文写的。本页按「玩家看到的情况 → 现在游戏怎么做 → 出处条目」列出来；出处是 DECISIONS 的条目标题，按标题搜。

**怎么过：**

1. **全局规则**（9 条）和**第十章三题**：一条一条看，各自认可或否决。
2. **其他**（9 条）：一条一条看。
3. **十月上旬的小偏离**（10 月 8–15 日各区域，约 90 条）：都是一个房间、一个人、一句话的小修，2026-10-23 起「批准的计划之内不再逐条问」，**推荐整批认可**，只挑出你想改的。
4. **十一月 PR 里按推荐生效的小选择**：同上，推荐整批认可。

已被后来的条目改掉的划了线（不必再看），只被部分改动的注了「部分」。数法：35 个条目里带「默认」或 default 字样的，拆成一件一件的决定共 112 条，其中 11 条划掉；后来的章节计划（逆灵宫到终章）各有一段「没问 owner 的默认」没在 DECISIONS 里标默认，这里没有展开。
