# 世界关系总览

_当前游戏内容里的势力、人物、关系与任务链；以 `game/data` 为准，ES2 里有但没移植的另行标出。_
_范围：已移植的九个区域（雪亭镇、老松岭、野羊山、卧龙岗与绮云镇、水烟阁、青石村、茅山灵心观、晚月庄、泓水南岸与山烟寺）。_
_用途：任务日志、势力声望、故事模式和主线设计的底稿。新增内容时同步更新。_

## 5. 任务与故事链

### 5.1 随机任务：朱鸿雪

- 入口：绮云镇棺材铺木门后。实战经验 ≤1000 被赶走。
- 十五档（1000 到 100000），220 条有效条目，全部是限时「杀」；按经验取档，连续完成会上调档位，超时下调。只在**游戏里已放置且能打**的目标中抽，整档没有就往下找；目标 84 个名字里 70 个已在游戏内，缺的 14 个在京师、乔阴和天驼关（严廷殷、李信、武官、赫造基、老兵、小兵、各队长、守城官兵、贵公子、三个小贩）。
- 奖励：经验、潜能、综合评价各取 bonus/2 加随机；玩家评价为负时评价奖励取负；潜能封顶 100。超时回来：气减半、连胜清零。
- 关联规则：每杀一人杀气 +1、受害者的仇杀标记记到玩家；杀自己师父 = 叛师（逐出门派、评价归零）；投降（最后一个要杀你的人站着就被拒）。
- 目标在各区域的分布：绮云镇 53、雪亭镇 39、晚月庄 33、茅山 21、野羊山 20、山烟寺 13、老松岭 10、青石村 3。

## 7. 可以直接拿来写主线和势力线的钩子

1. **皇叔与武林盟主**：於兰天武弃朝廷入水烟阁；水烟阁封地官府不能过问；正月十七推选盟主；南危水「为营救盟主遭小人暗算」的旧案；葬剑亭碑上四代七长老「以奸计害人」被合力击杀。
2. **岚城与旋芒宝剑**：主题故事的起点；萧辟尘来自岚城；晚月庄石牌「旋芒震日月」。
3. **杀手组织**：东方神教两代教主、杀手令牌、老妇的私生女、天山派与天邪派武学的交织、逍遥派探子、朱鸿雪发的全是刺杀。
4. **两寨世仇与双重身份**：刘安禄、魏无极、土匪老大、黄霸的来历、官府的告示和改道；野羊山北麓的逆灵宫。
5. **镖局书信**：陈剑秋 → 乔阴的忘忧草 → 京师陈天星，一条天然的跨区域成长线。
6. **预言**：七百年妖魔、村长「必有妖孽」、金仪彤的地煞纹。
