# 逆灵宫（`niling`）——内容笔记

第一个全原生区域（PR #196 A、#197 B、#198 C、D；DECISIONS「逆灵宫 A」～「逆灵宫 D」，计划 `build/plans/逆灵宫_计划.md`）。
这里只记代码和 PR 不记的三件事：残稿怎么接、三条路、互斥规则。

## 残稿怎么接

ES2 里逆灵宫只有 `doc/help/plan:26–31` 的四行（野羊山北麓一座全用黑砖砌成的大道观，两年前几乎将野羊山寨挑了，道士青一色黑衣黑冠，
大二寨主半年前失踪，三寨主每年纳供）、`d/snow/npc/woodcutter.c:15` 一句骂、`doc/skill/six-chaos-sword` 一句传闻（宫主使的「正是失传已久的
六阴天殇剑」）和 `doc/help/taoist:58` 一行禁书（逆灵天书）。没有一间房、一个人、一句对白。

| 残稿 | 落在哪 |
|---|---|
| 黑砖道观 | 七张图全是黑砖：山门、前院、货栈、前殿、丹房、账房、地牢、后殿、居所，后山的黑砖后墙 |
| 黑衣黑冠 | 黑衣复用 `es2:d/oldpine/npc/obj/black_cloth`，黑冠是原生物 `native:niling/black_crown`（戴上它道士当你自己人） |
| 三寨主纳供 | 黄霸的车在山路转角，吊进裂口；裂口顶的绞盘、烙「羊」字的箱子、货栈 |
| 大二寨主失踪 | 大寨主霍铮锁在地牢西牢房；二寨主「入丹房」（药架上的罐子、账册的一笔） |
| 六阴天殇剑 | 商玦、玄冥子用 ES2 的 `six-chaos-sword` 招式打，名目上叫天殇；残卷只是物 + 话题（owner Q3） |
| 逆灵天书 | 前殿案上的经书（look）、黑幡上的字、玄冥子掉的残卷 |
| 侮天鬼 | `doc/help/history:51–60` 找头的妖魔：唤首演出里黑焰中的无头黑影，看法 `headless` |
| 鬼卒 | `obj/npc/hell_guard.c` 的子阴鬼卒减弱，无尸（`vanishes`） |
| 石头 | `d/village/npc/woman1.c:18,22` 农妇的儿子，被逆灵宫的车借黑松山的名抓走 |

## 三条路（转角那张图只加数据）

转角的两个 act 服务「油布」「绳索」：钻油布（押车道士在场，先确认）、打倒押车道士攀绳（刷怪 `cleared_mark`）、戴着黄霸的黑冠攀绳
（话题「黑衣」给冠）。三条都记「进了逆灵宫」，任务 `way` 按印记记走的是哪条。地标没有条件，所以用 act 服务。

## 互斥规则（只用进图时的台上台下和任务账本键，不用计时器）

* 唤首之前牢门开不了（钥匙在玄冥子腰上）；唤首之后黑门才开（`found_by`「见过唤首」= 商玦的 `scene_mark`）；狱卒换成带钥匙的一版
  （`present`「见过唤首」，无钥匙版 `until` 同印记）。
* 救人（选项 `rescue` = 印记「救出了霍铮」）之后：后山的玄冥子 `until quest main.chapter3/choice/rescue`。
* 追宫主（选项 `chase` = 到 `niling.cliff_path`）之后：三间牢房的刷怪 `until quest main.chapter3/choice/chase`，地上物两具尸首 `present` 同键。
* 霍铮、石头跟着走（`follows_every_way`）；他们的刷怪只在玩家进地牢图时判，跟在身边的不受影响。
* 后果（D）全靠印记：「霍铮回了寨」（土匪让路、刘安禄回寨、黄霸改口）、「石头回家了」（农妇团圆）、「追出了后门」（黄霸坐大）。
